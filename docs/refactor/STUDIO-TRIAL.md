# 工作室试画

双击项目根目录的「打开双面板试画.command」。第一次打开会准备《雨夜来客》，共六张故事板和一张 Pending。每张是 2048×1152，含纸张、线稿和自由绘画三层。以后双击同一入口会回到这份项目。编辑后等底部显示「所有修改已暂存」，正常关闭窗口。

1. 光标移入第一张小图，在人物旁画一笔，再直接移到第二、第三张继续画。留意每张的第一笔是否跟手。
2. 在右侧画布调整细节，看左侧小图能否跟上。按一次撤销，检查两边的画面。
3. 拖动卡片顶部编号调整顺序。多选几张，按左右键逐张翻看，再在其中一张落笔。
4. 调整画布和网格的宽度，试着隐藏再恢复 Pending。记下最想常驻的面板，以及哪一步让你不得不停笔找按钮。

试画项目位于 `.hermes/studio-preview/project`。已暂存的内容会随整个项目目录保留。

要导出当前已暂存版本的文字分镜，在项目根目录运行以下命令。目标使用新的文件名。文档按当前故事板顺序列出动作和对白，Pending 留在项目内。

```sh
node scripts/export-workbench-markdown.mjs .hermes/studio-preview/project ./雨夜来客.md
```
